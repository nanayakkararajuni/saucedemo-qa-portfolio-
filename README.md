# SauceDemo — QA Testing Portfolio

## 1. Project Overview

This project is a Software Quality Assurance (QA) portfolio based on the SauceDemo (Swag Labs) e-commerce web application.

The purpose of this project is to gain practical experience in manual software testing, test case design, test execution, defect reporting, and basic test automation.

**Application Under Test:** https://www.saucedemo.com/

**Project Type:** Manual Testing and Planned Automation Testing

**Current Status:** In Progress

## 2. Project Objectives

The main objectives of this project are:

- Understand and analyze the application's functionality.
- Design clear and effective test scenarios and test cases.
- Perform positive and negative functional testing.
- Compare actual results with expected results.
- Identify and document reproducible software defects.
- Prepare professional test execution reports.
- Automate selected test scenarios using Playwright and TypeScript.

## 3. Test Scope

### Features Included in Testing

1. **Login Functionality**
   - Login with valid credentials
   - Login with invalid credentials
   - Login with empty fields
   - Login with a locked-out test account

2. **Product Listing**
   - Verify product information
   - Verify product visibility
   - Verify product sorting functionality

3. **Shopping Cart**
   - Add products to the cart
   - Remove products from the cart
   - Verify selected products and quantities

4. **Checkout Process**
   - Verify required-field validation
   - Complete a valid checkout
   - Verify order confirmation

5. **Navigation and Logout**
   - Verify navigation between pages
   - Verify logout functionality

### Features Excluded from Testing

- Real payment processing
- Advanced performance and load testing
- Penetration testing
- Backend database testing

## 4. Testing Approach

The project will use the following testing techniques:

- Manual functional testing
- Positive testing
- Negative testing
- Exploratory testing
- Regression testing of selected functionality

Test cases will include preconditions, test steps, expected results, actual results, and execution status.

Confirmed defects will be documented with steps to reproduce and supporting evidence where available.
